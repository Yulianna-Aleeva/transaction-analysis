# Анализ банковских операций
Веб-приложение для анализа личных финансов.  
Обрабатывает Excel-файл с транзакциями и анализирует банковские операции.  
Показывает статистику расходов, актуальные курсы валют и акций.  
Поиск, фильтрация, сортировка операций.


## Установка
1. Клонируйте репозиторий:  
* HTTPS
> https://github.com/Yulianna-Aleeva/transaction-analysis.git
* SSH
> git@github.com:Yulianna-Aleeva/transaction-analysis.git
2. Установите зависимости:
```sh
poetry install
```


## Запуск:
* Поместите файл `"operations.xlsx"` в папку [data](data) или
* В файле [.env](.env) укажите путь к эксель-файлу:  
> DATA_FILE=___ваш путь к файлу___  
* Вы можете указать свои валюты и акции в [пользовательских настройках](user_settings.json).
> По умолчанию установлены курсы валют и акции:
>> "CNY", "USD", "EUR" и "AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"
* Запустите консольный режим (проверка всех функций):  
> `python main.py`
* Для запуска веб-версии (Flask):  
> `python app.py` → `*Выход: CTRL+C`
* Перейдите по ссылке в браузер:
> http://127.0.0.1:5000


## Основные возможности веб-приложения
- Главная страница с приветствием по времени суток.
- Информация по картам, ТОП-операций.
- Актуальный курс валют (ЦБ РФ).
- Цены акций (MOEX → Yahoo Finance).
- Поисковые сервисы:
  - простой поиск по всему файлу;
  - по номеру телефона в описании;
  - по переводу или имени ФЛ.
- Анализ операций за последние 3 месяца:
  - ТОП-3 категорий по кешбэку;
  - ТОП-5 расходов;
  - ТОП-7 категорий. 
- Отчёты по расходам:
  - по категориям;
  - по дням недели;
  - по рабочим и выходным дням.
- Конвертация всех валют в рубли по актуальному курсу.
- Сохранение отчётов в JSON.


## Структура проекта
- `src/api/` – получение данных из внешних API
- `src/logs/` – настройка и хранение логов приложения
- `src/reports/` – генерация отчётов
- `src/services/` – поисковые и аналитические сервисы
- `src/utils/` – вспомогательные функции (загрузка, форматирование, фильтрация)
- `src/views.py` – формирование JSON для веб-страниц
- `src/constants` – константы и текстовые сообщения
- `tests/` – unit-тесты
- `data/` – папка для хранения Excel-файлов
- `templates/blocks` – HTML-блоки (карточки, таблицы, формы)
- `templates/index.html` – главная страница веб-приложения
- `.env` – путь к файлу
- `user_settings.json` – пользовательские настройки
- `app.py` – flask-приложение
- `main.py` – консольный запуск
